Recently, i learned basic Vim to help me take digital notes more smoothly. I found VimLegends, VimHero,.. site that help people learn Vim by turning each lesson into a mini-game. So instead of reading the document, try to remember all the frequently used commands,... i had to put thing in action.

It reminded me of the first time i learned typing back then in school. It was also a game, something like Mario, a character ran while i typed, the more accuratly and quickly i typed, the smoother the character moved.

This made me think about interactivity. In a game, i'm not only receiving information. i act, the game responds, and i learn from that response. This loop of action, feedback, and adjustment can help me understand something more than passive reading alone (especially with a perfectionist who want make sure to know everything before doing anything and then died by overwhelm)

I know that education through Game is not a new thing, it's been around for a few decades, but knowing and realizing is different (it's a bit embarassment to admire that i just realized it latetly). Games can teach skills, simulate situations, explore ideas, create empathy, or **help people practice difficult things in a low-stakes environment**. In many games, you cannot progress unless you understand what you have learned well enough to use it.

The important part is not that a game has points, badges, levels. Those are only surface-level game elements. What matters is whether the player can meaningfully interact with the system and learn from the consequences of their choices.

The other day, i was daydreaming about the fantasy future like in anime manga, where people could play an immersive virtual game that feel like going to another world. I think with AI, that might not be a fantasy anymore (?) (I'm not say we could do that, infact it's more likely to we can not, because it relate to brain connection, etc... but at least, we getting close to it). But if that day come, what will a "game" mean? it would have to be so much more, it's much be no limit. The only limit of a game is just the limit imagination of the game maker. So i wonder how game design in that imaginative future would look like, and seeking a way to get closer to it (i hope).
